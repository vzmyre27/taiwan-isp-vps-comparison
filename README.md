## 先搞清楚：双ISP住宅IP到底是什么

简单说，一个IP有两个属性——ASN（自治系统编号）和注册公司。如果这两个属性都指向家庭宽带运营商，那就是"双ISP住宅IP"；如果只有ASN对得上、公司不对，就是单ISP。再往下分，IP地址固定的是静态住宅IP，能换的是动态住宅IP。

为什么平台认这个？因为TikTok、Netflix、亚马逊这类平台的风控系统会区分"机房IP"和"家庭用户IP"。机房IP容易被当成机器人或代理流量，住宅IP则看起来像普通家庭在上网，账号权重和推荐量通常更稳。这也是双ISP VPS比普通VPS贵、但仍有市场的根本原因。

丽萨主机的台湾双ISP走的是中华电信Hinet线路，Hinet是台湾最大的ISP，IP池大、覆盖率高，住宅属性比较"正"。
